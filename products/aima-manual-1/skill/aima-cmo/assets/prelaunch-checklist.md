# Pre-launch checklist — [Business]

## Setup
- [ ] Workspace created (one per brand or client)
- [ ] Meta connected: Business Manager, Page, Instagram, ad account
- [ ] Google Ads connected
- [ ] Brand kit built (logo, colors, assets from kickoff)
- [ ] Pixel / tracking shows healthy on the dashboard
- [ ] Payment method is the business's, in the business's accounts
- [ ] Slack (or approval channel) connected if you'll use it

## Launch
- [ ] Pixel healthy
- [ ] Running in the business's own accounts, their payment method
- [ ] Offer in the ad = instant form = callback script
- [ ] At least 3–4 distinct creatives approved (several hooks, two formats, image + video)
- [ ] Google RSA: full headline coverage, minimal pinning, call + location assets on
- [ ] Goal mode: set-budget (move to scale once CPL holds)
- [ ] Starting daily budget defensible from customer value and margin: $[ ]/day
- [ ] Review level set (first weeks: see every action before it happens)
- [ ] Someone ready to call leads back in minutes: [name], within [X] min, after-hours: [plan]
- [ ] Everything paused; nothing has spent yet
